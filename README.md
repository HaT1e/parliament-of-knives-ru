# Русификатор для Vampire: The Masquerade — Parliament of Knives

Полный русский перевод текстов игры **Vampire: The Masquerade — Parliament of Knives**
(разработчик — Choice of Games, автор — Jeffrey Dean) на движке ChoiceScript.

Перевод охватывает всю игру: прологи, главы, диалоги, описания предметов,
интерфейс, подсказки и системные сцены.

## Что в репозитории

Все переведённые файлы лежат в папке `deploy/` — она повторяет структуру
внутри `app.asar`:

```text
deploy/
├── scenes/              # тексты игры
│   ├── *.txt            # исходный текст сцены ChoiceScript
│   └── *.txt.json       # упакованная версия для движка игры
├── credits.html         # экран титров
├── mygame.js            # стартовые значения и названия предметов
├── scene.js             # системные кнопки и сообщения о загрузке
└── ui.js                # элементы интерфейса
```

Файлы, которые не содержат переведённого текста (служебная логика, не
менявшаяся относительно оригинала), в репозиторий не входят. В частности,
`index.html`, `alertify.min.js`, `util.js` и прочие служебные файлы остаются
оригинальными — заменять их не нужно.

## Установка

1. Перейдите в папку игры (Windows):
   `\Steam\steamapps\common\Vampire The Masquerade Parliament of Knives\resources`
2. Скачайте **7-Zip** и плагин **Asar** для него, затем откройте этим архиватором файл `app.asar`.
3. Замените файлы внутри архива на файлы из папки `deploy/` этого репозитория, сохраняя структуру.
4. Сохраните архив и запустите игру.
